Clash Mimihomo 格式我的配置 → + → 添加配置链接
  1. 确认网络。使用订阅的设备需能访问本服务。家庭局域网部署时，先连接同一局域网（如同一 Wi-Fi）；在其他设备上，订阅地址不能是 127.0.0.1 或 localhost。
  2. 连接账户。在本页登录 MonoCloud。已连接时账户显示为一行，更换账户可点“切换账户”。管理入口的用户名是 admin，管理密码向部署者获取，与 MonoCloud 账户密码不同。
  3. 添加订阅。复制本页链接，在 Clash Mi 的“我的配置 → + → 添加配置链接”中粘贴并保存，选中该配置。
  4. 选择套餐和节点。使用规则模式；在 Proxy 组选择套餐，再在对应套餐组选择节点。GLOBAL 对应全局模式，日常分流使用规则模式。
  5. 连接并验证。开启连接，按系统提示允许 VPN，确认常用国内外网站能访问。切换节点仍在对应套餐组操作。
  • 更新配置。在 Clash Mi 手动更新同一订阅，重新连接。链接保持不变；首次升级到套餐分组时，请重新选择一次套餐和节点。
可选：增加 Tailscale 能力
  1. 开启并更新。在本页“订阅内容”选择“代理 + Tailscale”并保存，然后在 Clash Mi 更新原订阅、重新连接，不需要另建配置或更换链接。
  2. 触发首次连接。访问你自己的 Tailnet IP 或完整域名。Tailscale 按需启动，首次请求可能短暂超时。
  3. 获取授权链接。在“核心设置 → 日志等级”选择 info，重新连接并触发访问。打开“核心日志 → 右上角 ⋮ → 复制”，粘贴到私人备忘录，搜索 login.tailscale.com，打开 go to: 后面的完整链接。不要把整份日志粘贴进浏览器搜索框。
  4. 完成授权。保持 Clash Mi 的 VPN 连接，在浏览器登录 Tailscale 并确认设备加入自己的 Tailnet。等待连接就绪后，再访问 Tailnet IP 和完整域名，同时确认公网网站仍正常。
  5. 关闭可选能力。在本页“订阅内容”改回“仅代理”，保存后更新原订阅并重连，基础代理继续使用。不要为此删除客户端状态。

已在 iPhone 上的 Clash Mi 1.0.31.1703 验证基础接入和 Tailscale 叠加流程；套餐分组请按新版订阅重新选择。IPv6、子网路由及网络切换需另行验证。
